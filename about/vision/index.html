BHANG · VISION

Child of BHANG Glasses

What This Is

BHANG VISION is the Visioncube, a 1/1 on chain child of the BHANG glasses. It is a glass cube that uses OCM libraries and tools, shows the freeze era (Baseline ART) 9 series faces plus an ice back at mint, and keeps an open center for a coin blit.

The mint message on the cube is One plant. Many Faces.

Parent

Ordinals parent tag points at BHANG, inscription #124,622,117 on legacy sat. That link is provenance. The cube also hardcodes the parent inscription id and recursively loads leaf helpers from /content/ so the leaf geometry stays tied to the glasses art.

Three Sats as trinity

The host is inscribed once on the art sat. Two other sats can update the cube later without reminting the host.

Art Host 45,017,804,610 · #4610 · Block 9 450x Engine Sat 394,947,745,886 · THE WIZARDS OF ORD #2242 · Block 78 Coin Sat Not listed here · Block 9 450x (hardcoded in the cube; omitted from this page only)

Engine tips export BHANG_ENGINE.mount. Coin tips export BHANG_COIN.start.

Empty or broken tips fall back to baseline art and an empty center.

What You See

Baseline ART: glass walls, ice back, nine series showing present utilities explored from plant, optional orbital belt synced to chain reactive music. The center starts open. Face slots are front, right, top, left, bottom, back, and surround. The coin is not a face slot, it is a separate center billboard hop.

When a valid engine tip is present, faces and surround can change.

When a valid coin tip is present, the center paints from an offscreen blit each frame.

Runtime

On each visit the inscribed cube runs its own code. It recursively loads Three.js, fflate, p5, Tone.js, and parent HTML from fixed on chain inscription ids. It resolves engine and coin tips with /r/sat/<SAT>/at/-1, then /content/<id>. Latest tip wins.

Inside the inscription a tip loop refreshes about every 45 seconds. Opening this page starts that runtime. The site does not add its own poller.

How It's Built

Built with the open OCM Dimensions toolchain on the Three.js library path: compress to a gzip td= shell, then inscribe. Only the render code goes on chain.

Updates Without Remint

Reinscribe the engine sat to change faces and surround. Reinscribe the coin sat to change the center. The cube host file on the art sat does not need to move. Images or HTML without the BHANG markers do not update the cube, the host keeps baseline faces and an empty center.
